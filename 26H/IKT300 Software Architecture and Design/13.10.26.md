Defer binding
- Tactics can be used to bind values at compile time or build time
	- Component replacement
	- Compile-time parameterization
	- Aspects
- The following bind values at deployment, startup time or initialisation time:
	- Configuration-time binding
	- Resource files
- Tactics to bind values at runtime include the following:
	- Discovery (See chapter 7)
	- Interpret parameters
	- Shared repositories
	- Polymorphism
